texto

content (Conteudo)

Defina a largura da caixa (salvo elementos dde bloco)

Padding

Separa o Conteudo das bordas da caixa. E a margem interna

Border (borda)

Define normas para a caixa

Margin

Define a distancia entre uma caixa e outra

width (largura)

A largura total caixa, por padrão é o somatorio do conteúdo + padding (left/right) + border (left/right)

Height (altura)

A altura total da caixa, por padrão é o somatorio do conteudo + padding (top/bottom) + border (top/bottom)
